# ATHLETIX

**ATHLETIX** — интеллектуальная платформа для мониторинга физического состояния спортсменов, раннего выявления накопленной усталости и стресса и адаптации тренировочного плана.

Проект разработан в рамках **OVERCLOCK HACKATHON 2026**, трек **BioTech**.

## Проблема

Высокие тренировочные нагрузки без достаточного восстановления могут привести к:

* накоплению усталости;
* повышению уровня стресса;
* снижению качества восстановления;
* перегрузке организма;
* повышению риска травм.

Спортсмену и тренеру важно не только видеть отдельные показатели, но и понимать, когда текущая нагрузка становится слишком высокой.

## Решение

ATHLETIX объединяет показатели состояния спортсмена и анализирует их для оценки текущего уровня нагрузки.

Платформа учитывает:

* частоту сердечных сокращений;
* уровень усталости;
* восстановление;
* тренировочную нагрузку.

На основе этих показателей система рассчитывает условный уровень риска и формирует рекомендацию по тренировке или восстановлению.

## Основные функции

### Monitoring

Отображение текущих показателей спортсмена и динамики сердечного ритма.

### AI Coach

Анализ текущего состояния спортсмена и автоматическое формирование рекомендации по тренировке или восстановлению.

### Adaptive Schedule

Адаптация тренировочного плана в зависимости от текущего состояния спортсмена.

### Coach Dashboard

Обзор основных показателей спортсмена для тренера.

### History

Просмотр предыдущих показателей и изменений состояния спортсмена.

Рекомендация

В проекте реализован реальный аппаратный прототип смарт-пояса на базе ESP32 и подключённых датчиков.

В текущем MVP веб-приложение использует симулированные данные для демонстрации полного цикла работы платформы, интерфейса мониторинга и системы рекомендаций.

Arduino и смарт-пояс

Аппаратная часть ATHLETIX представляет собой носимый смарт-пояс для биомониторинга.

В составе устройства используются:

ESP32 — основной контроллер;
MPU6050 — датчик движения и ускорения;
BMP280 — датчик температуры и давления;
Pulse Sensor — датчик частоты сердечных сокращений.
Этап 1. Прототипирование и аппаратная отладка

На первом этапе электроника была собрана на беспаечной макетной плате (breadboard).

Для проверки работоспособности системы проводились:

проверка подключения датчиков;
программное сканирование шины I2C;
проверка адресов цифровых датчиков;
устранение проблем с контактами;
проверка считывания аналогового сигнала Pulse Sensor;
проверка данных акселерометра MPU6050;
проверка показателей BMP280;
тестирование работы ESP32.
Этап 2. Разработка корпуса и компоновка модулей

После проверки электроники компоненты были компактно размещены внутри защитного корпуса.

При сборке учитывалась эргономика устройства:

компактное расположение электронных компонентов;
защита модулей;
доступ к USB-питанию;
вывод провода Pulse Sensor;
удобное размещение датчика для контакта с телом пользователя.
Этап 3. Интеграция в смарт-пояс и испытания

На заключительном этапе электронный модуль был установлен на текстильную основу смарт-пояса.

Pulse Sensor располагается таким образом, чтобы обеспечить необходимый контакт с кожей пользователя.

После сборки проводилось тестирование устройства во время движения. Проверялись:

стабильность работы ESP32;
корректность считывания данных;
работа датчиков;
стабильность устройства во время движения;
удобство размещения аппаратного модуля.

Таким образом, аппаратная часть ATHLETIX была собрана в виде работающего прототипа носимого смарт-пояса.

Установка и запуск

Чтобы запустить ATHLETIX на своём компьютере:

1. Скачать проект

Склонируйте репозиторий:

git clone https://github.com/lanswx/athletix.git

Затем перейдите в папку проекта:

cd athletix
2. Установить необходимые библиотеки

В терминале выполните:

pip install -r requirements.txt

Эта команда установит Flask и другие необходимые зависимости.

3. Запустить приложение

Выполните:

python app.py

После запуска Flask запустит локальный сервер.

4. Открыть сайт

Откройте браузер и перейдите по адресу:

http://127.0.0.1:5000

После этого откроется ATHLETIX.

Работа аппаратной части

Код для ESP32 находится в:

arduino/fitness_belt.ino

Аппаратный прототип собирает данные с подключённых датчиков и представляет собой основу для дальнейшей передачи показателей в платформу ATHLETIX.

Текущая веб-версия демонстрирует обработку и визуализацию данных на стороне приложения с использованием симулированных показателей.
